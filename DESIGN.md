# 眼表图谱

## Visual direction

安静的解剖学习工作台：白色阅读区围绕深色模型台，结构颜色仅用于识别。

## Colors

CSS tokens use OKLCH: primary `oklch(.34 .159 262.4)`; background `oklch(1 0 0)`; ink `oklch(.25 .02 262)`; muted `oklch(.48 .025 262)`; stage `oklch(.22 .025 262)`.

Three.js material colors use renderer-compatible sRGB values. These are category colors, not tissue color measurements.

## Typography

System sans stack with PingFang SC and Microsoft YaHei, no remote font dependency. Headings 1.38–1.9rem; labels and reading panels retain compact hierarchy.

## Layout

Desktop: structure list, 3D stage, explanation. Tablet: explanation below. Phone: compact two-column selector, stage, explanation. Three learning views always visible.

## Interaction

Native buttons and checkboxes; mesh selection mirrors list selection. View switches restore structure visibility. Reset restores view-specific defaults. Motion starts only on user action; respects reduced-motion settings.
